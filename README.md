## Project Summary

- **Business Task**: Analyse usage patterns of Cyclistic bike-share users to provide insights for converting casual riders into annual members.

- **Data Source**: Cyclistic trip data provided by Coursera as part of the Google Data Analytics Professional Certificate Capstone Project.

- **Process**:
  
  1. Data collection & cleaning
 
  2. Data transformation (merging, filtering, formatting)

  3. Visualisation of usage patterns
 
  4. Generating business insights
 
- **Key Findings**:  

  - Casual riders use bikes mostly on weekends, while members ride more on weekdays.
 
  - Members take shorter, more frequent trips.

  - Marketing strategies can be targeted to casual riders during weekends to encourage membership.
